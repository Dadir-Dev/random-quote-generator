# 🌟 Random Quote Generator

A responsive, theme-rich Random Quote Generator built with HTML, CSS, and JavaScript.
This app lets users explore inspiring quotes from multiple categories, switch between light/dark/image themes, and copy quotes with one click.

# Live Demo

👉 View the Live Project Here

# Features

- 🎯 Filter quotes by category

- 🎨 Toggle between Dark, Light, and Image themes

- 🔄 Smooth quote transition animations

- 💾 Theme preference saved in localStorage

- ⌨️ Keyboard navigation (← / → / Space)

- 📋 Copy to clipboard feature with success feedback

- 🌅 Background image switching in “Image Mode”

- 💬 Responsive and mobile-friendly design
